# Assinatura Android (sideload)

Keystore de demonstração para instalar o APK fora da Play Store.

- Arquivo: `linkup-release.keystore`
- Alias: `linkup`
- Senha da loja e da chave: `linkup-sideload`

Uma release nova com a mesma chave atualiza o app sem desinstalar. Não use esta chave em produção comercial.

# Código de conduta

Este é um projeto acadêmico de seis pessoas. Colaboração clara vale mais do que velocidade isolada.

- Critique o código, não a pessoa.
- Avise cedo se um contrato entre camadas vai mudar.
- Não empurre para `main` sem Pull Request.
- Não commite segredos (`.env`, chaves de API).
- Peça ajuda na Issue ou no PR em vez de silenciar um bloqueio.

Incidentes: fale com o Tech Lead (@The-P-P).
